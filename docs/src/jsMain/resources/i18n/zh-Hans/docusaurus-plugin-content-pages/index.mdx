<ktjs-features section-title="为什么用这个 wrapper" tinted>

<ktjs-feature icon="lucide:type" title="覆盖完整公开面">入口对象、`RenderResult`、`ParseResult`、`MermaidAPI`、`Diagram`、图型定义契约、图标包、布局 loader —— 上游 `.d.ts` 导出的每一个成员都有对应声明。</ktjs-feature>

<ktjs-feature icon="lucide:list-tree" title="配置就是真类型">`MermaidConfig` 由 mermaid 自己的声明生成：36 个接口、572 个成员，每个字面量联合都有常量对象，所以 `MermaidConfigThemes.dark` 是编译器认识的值。</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="对着真库测">测试在 Chromium 里真的渲染、解析、配置图表；字面量常量逐条对照上游字符串，重新生成的文件不会悄悄漂移。</ktjs-feature>

<ktjs-feature icon="lucide:mouse-pointer-click" title="能动手的演示页">演示页通过 wrapper 渲染，带预置图源与主题切换 —— 和调用方要写的三个调用完全一样。</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="文档也是 Kotlin">本站就是由 ktjs-docusaurus 构建的 Kotlin/JS 模块：类型化配置与侧边栏、Markdown 页面、中英双语。</ktjs-feature>

<ktjs-feature icon="lucide:rocket" title="Pages 与发布已接好">`pagesSite` 组装文档、演示与 API 文档；`release.yml` 负责签名并经由 Maven Central hub 发布模块。</ktjs-feature>

</ktjs-features>
