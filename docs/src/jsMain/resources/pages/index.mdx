<ktjs-features section-title="Why this wrapper" tinted>

<ktjs-feature icon="lucide:type" title="The whole public surface">The entry object, `RenderResult`, `ParseResult`, `MermaidAPI`, `Diagram`, the diagram-definition contracts, icon packs, layout loaders — every upstream `.d.ts` export has a declaration.</ktjs-feature>

<ktjs-feature icon="lucide:list-tree" title="Config as real types">`MermaidConfig` is generated from mermaid's own declarations: 36 interfaces, 572 members, and a constants object for every string-literal union, so `MermaidConfigThemes.dark` is a value the compiler knows.</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="Tested against the library">The tests render, parse and configure real diagrams in Chromium; literal constants are asserted against the upstream strings, so a regenerated file cannot drift unnoticed.</ktjs-feature>

<ktjs-feature icon="lucide:mouse-pointer-click" title="A demo that does the work">The demo page renders through the wrapper with preset diagram sources and a theme selector — the same three calls a consumer makes.</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="Docs are Kotlin too">This site is a Kotlin/JS module built by ktjs-docusaurus: typed configuration and sidebars, Markdown pages, English and Chinese.</ktjs-feature>

<ktjs-feature icon="lucide:rocket" title="Pages and release wired">`pagesSite` assembles the documentation, the demo and the API reference; `release.yml` signs and publishes the module through the Maven Central hub.</ktjs-feature>

</ktjs-features>
